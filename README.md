# Поднятие уровня в одиночку (Solo Leveling)

Веб-приложение для геймификации саморазвития: навыки с уровнями и опытом,
задания с наградами в XP, таймер и тренажёр памяти в виде дерева навыков.

## Возможности

- **Навыки** — создание, редактирование, удаление; опыт и автоматическое повышение уровня.
- **Задания** — ежедневные и «задание дня», награда в XP начисляется выбранному навыку.
- **Таймер** — обратный отсчёт для рабочих сессий.
- **Тренажёр памяти** (`page2.html`) — дерево уровней с запоминанием чисел и слов; полученный опыт идёт в те же навыки, что и на главной.
- **Аккаунты** — регистрация и вход через API; пароли хранятся в виде bcrypt-хешей, сессия живёт в httpOnly-куке.

## Быстрый старт

```bash
npm install
npm start           # http://localhost:3000
```

Режим разработки с автоперезапуском:

```bash
npm run dev
```

Тесты API:

```bash
npm test
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт HTTP-сервера |
| `HOST` | `0.0.0.0` | Интерфейс прослушивания |
| `USERS_FILE` | `./users.json` | Файл-хранилище пользователей |
| `SESSION_SECRET` | случайный | Секрет подписи сессионной куки (**задайте в продакшене**, иначе сессии сбрасываются при рестарте) |
| `BCRYPT_ROUNDS` | `10` | Стоимость хеширования пароля |
| `NODE_ENV` | — | При `production` кука сессии помечается `Secure` |

## API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/register` | Регистрация; 409, если логин занят |
| `POST` | `/api/login` | Вход; 401 при неверных данных |
| `POST` | `/api/logout` | Выход, уничтожение сессии |
| `GET` | `/api/me` | Текущий пользователь или 401 |
| `PUT` | `/api/me/profile` | Сохранение профиля `{ level, xp, skills }` |
| `POST` | `/register` | Устаревший алиас: вход или регистрация |

Ответы никогда не содержат пароль или его хеш.

## Хранение данных

- Навыки и задания хранятся в `localStorage` браузера (ключ `levelUpData`), прогресс тренажёра — в `memoryTrainerData`. Данные можно скопировать, скачать и загрузить из JSON через боковое меню.
- Учётные записи лежат в `users.json` на сервере. Файл создаётся автоматически и **не коммитится** в Git.
