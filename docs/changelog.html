Регистрация вместо входа

Единственный эндпоинт /register при совпадении логина и пароля авторизовывал пользователя, а при несовпадении отвечал 400 с текстом «Пользователь с таким логином уже существует, пароль не совпадает!» — это прямое подтверждение существования учётки. Теперь есть раздельные /api/register (409 при занятом логине) и /api/login (одинаковый 401 для любой неудачи). Старый путь сохранён как алиас ради совместимости.

Полное отсутствие валидации

Прежний код принимал что угодно, включая {} и вложенные объекты вместо строк, и писал это в файл. Добавлены: проверка типов, регулярное выражение для логина, границы длины пароля, лимит тела запроса 16 КБ и ограничение частоты — 20 попыток за 15 минут. Тест server #5.

XSS на странице профиля

userInfoDiv.innerHTML = `
  <p><strong>Логин:</strong> ${userData.username}</p>
`;

Логин <img src=x onerror=…> исполнялся как разметка. Сейчас все значения выводятся через textContent и createTextNode; тест pages #9 запрещает возврат innerHTML в этот файл.

Падение сервера на пустом файле

function readUsers() {
  if (!fs.existsSync(usersFilePath)) {
    fs.writeFileSync(usersFilePath, JSON.stringify([]));
  }
  const data = fs.readFileSync(usersFilePath);
  return JSON.parse(data);      // ← SyntaxError на пустом файле
}

В репозитории лежал пустой users.json, поэтому первый же запрос ронял процесс. Новая версия обрабатывает отсутствие файла, пустоту, не-массив и битый JSON, а запись стала атомарной. Тест server #1.

function checkLevelUp(skill) {

function applyLevelUps(skill) {
  let gained = 0;
  while (skill.exp >= EXP_PER_LEVEL) {
    skill.exp -= EXP_PER_LEVEL;
    skill.level += 1;
    gained += 1;
  }
  return gained;
}

  • Синхронизация игрового прогресса с сервером. Эндпоинт PUT /api/me/profile готов и протестирован, но интерфейс пока пишет только в localStorage.

  • Переход на СУБД и Redis для сессий. Нужен, если приложение выйдет за рамки одного инстанса.
  • Точный таймер. Сейчас он считает тики setInterval, а не реальное время.
  • Достижения и статистика. Пункты меню убраны, потому что функциональности за ними не было.
