Инициализация данных

// Данные хранятся в общем модуле assets/skills-store.js,
// чтобы страница прокачки (page2.html) работала с теми же навыками.
const EXP_PER_LEVEL = SkillsStore.EXP_PER_LEVEL;
let data = SkillsStore.load();
SkillsStore.save(data);

let currentSkillIndex = 0;

SkillsStore.load() уже нормализует данные: гарантирует массивы, наличие дефолтного навыка и корректные числа. Повторное сохранение сразу после загрузки фиксирует нормализованную версию — если в хранилище лежал мусор, он чинится при первом же открытии страницы.

Почему <script src="assets/skills-store.js"> без defer

Инлайновый скрипт обращается к SkillsStore сразу при разборе страницы. Атрибут defer откладывает выполнение внешнего файла до конца парсинга, то есть после инлайнового кода — получилась бы ошибка SkillsStore is not defined. Обычный блокирующий тег гарантирует нужный порядок. Именно это ловит тест pages #1, который падает при любой ошибке JS на странице.

Данные: импорт и экспорт

saveData(): void

Тонкая обёртка над SkillsStore.save(data). Вызывается после каждого изменения — приложение не держит «несохранённого» состояния.

generateId(): string

Делегирует в SkillsStore.generateId(): crypto.randomUUID(), а если браузер старый — строка вида _k3n8s2p1x.

copyDataAsJSON(): void

Кладёт JSON.stringify(data, null, 2) в буфер обмена через navigator.clipboard.writeText и показывает уведомление. В браузере API доступно только на HTTPS или localhost, поэтому ошибка логируется в консоль.

downloadDataAsJSON(): void

Создаёт Blob с данными, генерирует временный objectURL, кликает по невидимой ссылке <a download="levelUpData.json"> и освобождает URL через revokeObjectURL — без этого блоб остался бы в памяти вкладки.

const reader = new FileReader();

Загруженный файл обязательно проходит normalize() — чужой или устаревший JSON не сможет привести приложение в нерабочее состояние. Сброс currentSkillIndex = 0 нужен потому, что в новом наборе навыков прежнего индекса может не быть.

Навыки

renderSkill(): void

Главная функция отрисовки. Порядок действий:

  1. если навыков нет — создаёт дефолтный через SkillsStore.createDefaultSkill();
  2. чинит индекс, если он вышел за пределы массива (например, после удаления);
  3. пишет название и уровень;
  4. закрашивает клетки опыта: index < Math.min(skill.exp, EXP_PER_LEVEL) — ограничение защищает от «переполнения» шкалы, если опыт временно больше пяти;
  5. обновляет подпись «3 / 5 XP» и описание навыка;
  6. подсвечивает блок красным, если навык дефолтный.
Удалённый мёртвый код

Раньше в этом же цикле на каждую клетку вешался обработчик onmouseenter, который искал элемент #guiSound и пытался проиграть звук. Элемента с таким id в разметке никогда не существовало — код выполнялся вхолостую при каждом наведении. Он удалён, а тест pages #1 проверяет, что #guiSound действительно нет.

skillSquareClick(e: Event, index: number): void
skill.exp = (skill.exp > index) ? index : (index + 1);

Клик по клетке работает как переключатель: если опыта больше номера клетки — опыт уменьшается до этого номера (снимаем лишние), иначе увеличивается до index + 1 (закрашиваем по клетку включительно). Затем — сохранение, перерисовка и проверка уровня. e.stopPropagation() не даёт клику всплыть до блока навыка и открыть окно редактирования.

prevSkill(): void / nextSkill(): void

Переключение навыков стрелками. У nextSkill есть особенность: на последнем навыке она не упирается в конец, а создаёт новый — это быстрый способ добавить навык.

addNewSkill(): void

Добавляет { name: "Новый навык", level: 1, exp: 0, default: false }, делает его текущим, сохраняет, обновляет выпадающие списки заданий и показывает уведомление.

openSkillsManager(): void / closeSkillsManager(): void

Модальное окно «Мои навыки». Для каждого навыка строится строка с названием, уровнем и опытом: клик по названию делает навык текущим и закрывает окно, кнопка «Удалить» спрашивает подтверждение и убирает навык. У дефолтного навыка кнопка удаления заблокирована (disabled с подсказкой). После удаления окно перерисовывается вызовом самой себя.

removeBtn.onclick = () => {
  if (!confirm(`Удалить навык «${skill.name}»?`)) return;
  data.skills = data.skills.filter(item => item.id !== skill.id);
  if (currentSkillIndex >= data.skills.length) currentSkillIndex = data.skills.length - 1;
  saveData();
  renderSkill();
  updateXpSkillSelect();
  openSkillsManager();
  showNotification("Навык удалён!");
};

openSkillModal() / closeSkillModal() / saveSkillModal()

Редактирование навыка. Дефолтный навык редактировать нельзя — окно даже не откроется. При сохранении проверяются: непустое название, уровень ≥ 1, опыт в диапазоне 0…EXP_PER_LEVEL. После сохранения флаг default снимается: отредактированный навык становится обычным.

checkLevelUp(skill: Skill): void
// Повышаем уровень столько раз, сколько хватает опыта:
// при награде в 20 XP игрок получает 4 уровня, а не один.
function checkLevelUp(skill) {
  const levelsGained = SkillsStore.applyLevelUps(skill);
  if (levelsGained > 0) {
    showNotification(`Уровень повышен до ${skill.level}!`);
    saveData();
    renderSkill();
  }
}

Сами правила уровней живут в store, страница отвечает только за уведомление и перерисовку. Проверяется тестом pages #2: 22 XP → 4 уровня и остаток 2 XP.

Задания

renderTasks(): void

Полностью пересобирает список #taskList. Для каждой задачи создаётся карточка: название (зачёркнутое, если выполнено), награда, тип, полоса прогресса и три кнопки — «Выполнить», «Ред.», «Удалить». Все элементы создаются через createElement, а тексты задаются innerText, поэтому название задания не может выполниться как разметка.

const progressFill = document.createElement("div");
progressFill.className = task.completed ? "bg-green-500 h-full" : "bg-cyan-500 h-full";
progressFill.style.width = task.completed ? "100%" : "0%";

Раньше здесь стояла заглушка progressFill.style.width = "50%"; // Placeholder внутри условия if (!task.completed && task.duration), причём поле duration у задач никогда не создавалось — полоса рисовалась случайным образом и всегда врала.

addTask(): void

Читает форму, требует непустое название, проверяет, что награда — неотрицательное число (иначе подсвечивает поле через highlightField), создаёт задачу с createdAt и xpSkill из выпадающего списка, очищает форму и перерисовывает список.

completeTask(id: string): void
  1. находит задачу; если она уже выполнена — только уведомление;
  2. если награда корректна, ищет навык по task.xpSkill, при отсутствии берёт первый и предупреждает об этом;
  3. начисляет опыт и вызывает checkLevelUp;
  4. ставит completed = true и completedAt;
  5. сохраняет, перерисовывает задачи и навык, показывает уведомление.

Проверяется тестом pages #3: награда 7 XP переводит навык с уровня 1 на 2 и оставляет 2 XP.

openTaskModal(id) / closeTaskModal() / saveTaskModal()

Редактирование задания. Идентификатор редактируемой задачи хранится в currentTaskId. При сохранении заново проверяются название и награда, затем поля перезаписываются и список перерисовывается.

highlightField(fieldId: string): void

Подсвечивает поле красной рамкой с пульсацией на 1,5 секунды — визуальная обратная связь при ошибке ввода.

Таймер

startTimer() / updateTimer() / updateTimerDisplay() / pauseTimer() / resetTimer() / formatTime(time)

Состояние — два модуля-уровня переменных: timerInterval и объект remainingTime = { hours, minutes, seconds }.

ФункцияПоведение
startTimerЧитает три поля, отказывается стартовать при нулях или отрицательных значениях, чистит прежний интервал и запускает setInterval(updateTimer, 1000)
updateTimerВычитает секунду с «займом» у минут и часов; при полном нуле останавливает интервал, показывает «Время истекло!» и вызывает resetTimer
updateTimerDisplayПишет отформатированное время в #timerDisplay
pauseTimerОстанавливает интервал, сохраняя остаток времени
resetTimerПауза + обнуление состояния и полей ввода
formatTimepadStart(2, '0') для каждой части → 01:05:09
Известное ограничение

Таймер основан на setInterval и считает «тики», а не реальное время. В фоновой вкладке браузер прореживает таймеры, поэтому отсчёт может отстать. Точное решение — запоминать Date.now() старта и вычислять остаток от него.

Утилиты и инициализация

updateXpSkillSelect(): void

Перезаполняет оба выпадающих списка навыков — в форме создания и в окне редактирования задания. option.value — это skill.id, поэтому переименование навыка не рвёт связь с задачами.

showNotification(message: string): void

Показывает «системное» уведомление в правом нижнем углу на три секунды. Текст задаётся innerText.

document.addEventListener('DOMContentLoaded', …)

Далее навешиваются обработчики кнопок скачивания и загрузки JSON, кнопки мобильного меню, и выполняется первичная отрисовка: updateXpSkillSelect(), renderSkill(), renderTasks(), animateStarfield().

Важная деталь: подпись кнопки меняется у вложенного <span id="regBtnLabel">, а не у самой ссылки. Раньше текст присваивался всему элементу <a> и стирал иконку Font Awesome внутри него.

toggleSidebar(): void

Переключает класс сдвига боковой панели на мобильных экранах.

animateStarfield(): void

Фон: 300 звёзд на <canvas id="starsCanvas">, каждая со своей скоростью; на каждом кадре requestAnimationFrame перерисовываются круги, вышедшие за границу «телепортируются» на противоположную сторону. Канвас растягивается по размеру окна и обновляется по событию resize.
