page2.html — тренажёр памяти

562 строки: бесконечное дерево уровней, которое можно таскать мышью и пальцем, генерация чисел и слов, отсчёт времени с шагом 0,1 секунды и начисление опыта в общие навыки.

Узлы расставлены зигзагом: первый по центру, чётные — на 25% ширины, нечётные — на 75%, шаг по вертикали 200 пикселей. Соседние соединяются линиями, которые пересчитываются при каждом изменении дерева.

Генерация заданий

generateWord(length: number): string
function generateWord(length) {
  return Array.from({ length }, () =>
    consonants[Math.floor(Math.random() * consonants.length)]
  ).join('');
}

Собирает случайное «слово» только из согласных — такую последовательность нельзя проговорить, поэтому её приходится запоминать визуально, а не фонетически. На уровнях, кратных четырём, вместо случайного набора берётся осмысленное слово из массива words — небольшая передышка.

Дерево уровней

createLevelNode(level: number): HTMLElement

Создаёт узел и вычисляет все его параметры из номера уровня:

const speed = 1 + 0.2 * (level - 1);          // скорость показа
const xpReward = 10 + 5 * (level - 1);        // награда
const digits = 4 + Math.floor((level - 1) / 3); // длина числа/слова
const isWordLevel = level % 2 === 0;          // чётные уровни — слова

Параметры кладутся в data-атрибуты (data-level, data-speed, data-xp, data-digits, data-type, data-hint) — DOM выступает хранилищем состояния узла, отдельной структуры в JS нет.

Что чинило это изменение

Раньше условие было level < currentLevel → «пройден». Но currentLevel увеличивался только когда следующего узла ещё не существовало, поэтому при обычном прохождении прогресс терялся: после перезагрузки пройденные уровни снова становились доступными или закрытыми. Теперь есть явный список completedLevels, а тест pages #8 проверяет восстановление после перезагрузки.

createConnectionLine(node1: Element, node2: Element): void
const deltaX = x2 - x1;
const deltaY = y2 - y1;
const distance = Math.sqrt(deltaX * deltaX + deltaY * deltaY);
const angle = Math.atan2(deltaY, deltaX) * (180 / Math.PI);

line.style.width = distance + "px";
line.style.top = y1 + "px";
line.style.left = x1 + "px";
line.style.transform = `rotate(${angle}deg)`;

Линия — это div высотой 2 пикселя, повёрнутый вокруг левого края (transform-origin: 0 50%). Длина — расстояние между центрами узлов, угол — арктангенс разности координат. Координаты берутся из getBoundingClientRect() с поправкой на положение контейнера.

updateAllConnections(): void

Удаляет все линии и рисует заново для каждой пары «уровень − 1 → уровень». Вызывается после прохождения уровня и при первоначальной сборке дерева.

Сохранение прогресса

saveProgress(): void / loadProgress(): void
function saveProgress() {
  const data = {
    xp: xp,
    currentLevel: currentLevel,
    completedLevels: Array.from(completedLevels)
  };
  localStorage.setItem('memoryTrainerData', JSON.stringify(data));
}
try {
  const parsed = JSON.parse(data);
  xp = Number(parsed.xp) || 0;
  currentLevel = Number(parsed.currentLevel) || 1;
  completedLevels = new Set(Array.isArray(parsed.completedLevels) ? parsed.completedLevels : []);
  renderXp();
} catch (e) {
  console.error('Ошибка загрузки данных:', e);
  xp = 0;
  currentLevel = 1;
  completedLevels = new Set();
}

Загрузка устойчива к битому JSON и к старому формату без поля completedLevels: в этом случае список просто окажется пустым, а игра продолжится.

Прохождение уровня

startTraining(node: Element): void
  1. закрытые и уже пройденные узлы игнорируются;
  2. по data-type генерируется число или слово нужной длины;
  3. время показа 4 / speed кладётся в timeLeft;
  4. заполняются подсказка, само задание и табло времени, заголовок второго шага меняется на «Введите слово:» или «Введите число:»;
  5. показывается модальное окно, запускается интервал с шагом 100 мс;
  6. когда время вышло — nextStage().
addExtraTime(): void

Кнопка «+3 сек» — добавляет три секунды к текущему показу. Полезно на высоких уровнях, где число мелькает меньше полутора секунд.

nextStage(): void / closeModal(): void

Переключение с экрана показа на экран ввода и закрытие окна. Обе функции первым делом гасят интервал — иначе он продолжал бы работать в фоне.

Дерево бесконечно: как только пройден последний видимый уровень, тут же создаётся следующий. Math.max нужен, чтобы прохождение старого уровня не понижало достигнутый прогресс.

Опыт

renderXp(): void / updateXP(amount: number): void
function renderXp() {
  document.getElementById('xpCounter').textContent = xp;
  document.getElementById('xpProgress').style.width = `${xp % 100}%`;
}

function updateXP(amount) {
  const gained = Number(amount) || 0;
  xp += gained;
  renderXp();
  saveProgress();

  // Опыт из тренажёра теперь попадает и в навыки на главной странице.
  const result = window.SkillsStore && SkillsStore.awardXp(gained);
  if (result && result.levelsGained > 0) {
    const feedback = document.getElementById('feedback');
    feedback.textContent = `Правильно! Навык «${result.skill.name}» — уровень ${result.skill.level}!`;
  }
}
Два исправления в одной функции

Во-первых, добавлен saveProgress(): раньше опыт сохранялся только внутри checkAnswer и часть прогресса могла потеряться. Во-вторых, появился вызов SkillsStore.awardXp() — до этого тренажёр и главная страница вели независимый учёт, и заработанный опыт нигде, кроме этой страницы, не отражался. Проверяется тестом pages #6.

Проверка window.SkillsStore && … оставляет страницу работоспособной, даже если общий модуль не загрузился.

Перетаскивание дерева

Полотно высотой 20000 пикселей нельзя прокрутить обычным скроллом — страница использует overflow: hidden. Вместо этого дерево двигают мышью или пальцем:

СобытиеДействие
mousedown / touchstartВключает режим перетаскивания, запоминает стартовые координаты, отключает CSS-переход
mousemove / touchmoveСчитает смещение и применяет transform: translate(x, y); preventDefault() гасит прокрутку страницы на мобильном
mouseup / touchendВыключает режим, возвращает плавный переход

Свойство touch-action: none у контейнера и user-select: none у узлов предотвращают конфликт с жестами браузера и случайное выделение текста при перетаскивании.

Инициализация

document.addEventListener("DOMContentLoaded", () => {
  loadProgress();
  const maxLevel = Math.max(currentLevel, ...completedLevels, 1);
  for (let level = 1; level <= maxLevel; level++) {
    createLevelNode(level);
  }
  updateAllConnections();
});

Дерево отстраивается до максимального из достигнутых уровней. Раньше цикл шёл level < currentLevel с отдельным созданием текущего узла, из-за чего при рассинхронизации currentLevel и реального прогресса часть узлов не появлялась.
