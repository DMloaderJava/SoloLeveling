Что это за приложение

«Поднятие уровня в одиночку» — веб-приложение для геймификации саморазвития в эстетике Solo Leveling: неоновый интерфейс, звёздное небо, «системные» уведомления. Пользователь заводит навыки, выполняет задания, получает за них опыт (XP) и повышает уровни. Отдельная страница — тренажёр памяти в виде дерева уровней, где нужно запоминать числа и слова за ограниченное время.

★ Навыки

Создание, редактирование, удаление, переключение. Уровень и шкала опыта из пяти клеток. При накоплении 5 XP уровень растёт автоматически.

✔ Задания

«Ежедневное» и «задание дня». У каждого — награда в XP и навык, которому эта награда достаётся.

⏱ Таймер

Обратный отсчёт с часами, минутами и секундами, паузой и сбросом. Нужен для рабочих сессий.

⌘ Тренажёр памяти

Бесконечное дерево уровней: числа и слова, скорость показа растёт с уровнем, награда — XP в те же навыки, что и на главной.

⚿ Аккаунты

Регистрация и вход через REST API. Пароли хранятся bcrypt-хешем, сессия — в httpOnly-куке.

↔ Импорт / экспорт

Данные можно скопировать в буфер, скачать файлом levelUpData.json и загрузить обратно.

Чего в репозитории намеренно нет

users.json не хранится в Git — это runtime-файл с учётными записями, он создаётся сервером при первой регистрации и попадает в .gitignore. node_modules/ тоже игнорируется, зависимости ставятся из package-lock.json.

Три минуты до запуска

git clone https://github.com/DMloaderJava/SoloLeveling.git
cd SoloLeveling
npm install
npm start        # http://localhost:3000
npm test         # 19 тестов, все должны быть зелёными
