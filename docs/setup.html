Установка и запуск

Как поднять проект локально, что означает каждая команда, какие переменные окружения существуют, как выложить приложение на сервер и что делать, если что-то не запускается.

Установка

git clone https://github.com/DMloaderJava/SoloLeveling.git
cd SoloLeveling
npm install

npm install поставит пять рантайм-зависимостей и одну для разработки:

bcryptjsruntimeХеширование и проверка паролей
express-sessionruntimeСессии в httpOnly-куке sl.sid
helmetruntimeБезопасные HTTP-заголовки
express-rate-limitruntimeОграничение попыток входа и регистрации

Про npm audit

Аудит показывает три moderate-уязвимости в транзитивном пакете qs, который тянет Express 4. Прямого исправления в апстриме на момент написания нет; на функциональность и безопасность нашего кода это не влияет — эндпоинты не принимают сложные вложенные query-строки.

Переменные окружения

Все читаются в начале server.js, ни одна не обязательна для локального запуска.

ПеременнаяПо умолчаниюОписание
PORT3000Порт HTTP-сервера. Раньше был захардкожен — теперь настраивается
HOST0.0.0.0Интерфейс прослушивания. 0.0.0.0 нужен внутри контейнеров и превью-сред
USERS_FILE./users.jsonПуть к файлу с учётками. Тесты подставляют временный файл
SESSION_SECRETслучайные 32 байтаСекрет подписи куки. Задайте в продакшене, иначе после рестарта все сессии становятся недействительными
BCRYPT_ROUNDS10Стоимость хеша. В тестах снижается до 4 ради скорости
NODE_ENV—При значении production кука помечается флагом Secure (только HTTPS)
 
export NODE_ENV=production
export SESSION_SECRET="$(openssl rand -hex 32)"
export PORT=8080
export USERS_FILE=/var/lib/sololeveling/users.json
npm start
Обязательно в продакшене

1) Задайте SESSION_SECRET — иначе при каждом перезапуске генерируется новый секрет и пользователей «выкидывает». 2) Поставьте NODE_ENV=production и терминируйте HTTPS на реверс-прокси: без этого кука сессии уйдёт по открытому HTTP.

Проверка, что всё работает

curl -s -o /dev/null -w "%{http_code}\n" localhost:3000/            # 200 — главная
curl -s -X POST localhost:3000/api/register \
  -H 'Content-Type: application/json' \
  -c cookies.txt \
  -d '{"username":"hunter","password":"secret123"}'                 # 201 + JSON пользователя

curl -s -b cookies.txt localhost:3000/api/me                        # данные текущего пользователя
cat users.json                                                      # внутри passwordHash, а не пароль

Открыть документацию

Этот сайт лежит в папке docs/ и раздаётся тем же сервером:

npm start
# затем откройте http://localhost:3000/docs/

Документация — статические файлы без сборки, поэтому её можно опубликовать на GitHub Pages: Settings → Pages → Source: main, папка /docs.

Деплой приложения

Вариант 1. Node-хостинг (полная функциональность)

Render, Railway, Fly.io, VPS с systemd — подойдёт любой, где можно выполнить npm ci && npm start. Файл users.json должен лежать на постоянном диске, иначе учётки исчезнут при передеплое — для этого и нужна переменная USERS_FILE.

[Service]
WorkingDirectory=/opt/sololeveling
Environment=NODE_ENV=production
Environment=SESSION_SECRET=подставьте_свой_секрет
Environment=USERS_FILE=/var/lib/sololeveling/users.json
ExecStart=/usr/bin/node server.js
Restart=always

Вариант 2. Только статика (GitHub Pages)

Страницы index.html, page2.html и вся игровая логика работают без сервера: навыки, задания, таймер и тренажёр держатся в localStorage. Не будет только аккаунтов — login.html и userinfo.html покажут сообщение «Сервер недоступен». Это ожидаемое поведение, а не ошибка: запросы к /api/* просто некуда отправлять.

Частые проблемы

СимптомПричинаРешение
Cannot find module 'express' Не выполнен npm install npm install в корне репозитория
EADDRINUSE: address already in use :::3000 Порт занят другим процессом PORT=3001 npm start либо остановить занявший процесс
Вход проходит, но /api/me отдаёт 401 Кука не сохраняется: запрос ушёл с другого origin или без credentials Открывайте приложение с того же адреса, что и API; в fetch указан credentials: 'same-origin'
После рестарта всех «разлогинило» Не задан SESSION_SECRET — сгенерировался новый Зафиксировать секрет в переменных окружения
Слишком много попыток. Повторите позже. Сработал rate limit: 20 запросов за 15 минут с одного IP Подождать окно либо поднять лимит в server.js для стенда
Навыки пропали Очищен localStorage браузера — данные игры хранятся там Восстановить из ранее скачанного levelUpData.json (кнопка «Загрузить данные»)
Тесты падают с ошибкой jsdom Не установлены dev-зависимости (npm ci --omit=dev) npm install без флагов
