114 строк, единственный модуль, который знает формат данных навыков. Через него работают и главная страница, и тренажёр памяти — именно поэтому опыт, заработанный в тренажёре, попадает в те же навыки.

Зачем модуль появился

БЫЛО СТАЛО index.html index.html ──┐ └── localStorage['levelUpData'] ├──▶ SkillsStore ──▶ localStorage['levelUpData'] page2.html ──┘ page2.html └── localStorage['memoryTrainerData'] page2.html также ведёт своё localStorage['memoryTrainerData'] две независимые системы: (прогресс дерева) опыт из тренажёра нигде не учитывался один формат, одни правила уровней

Кроме объединения данных модуль решает вторую задачу: правила «сколько опыта нужно на уровень» больше не размазаны по страницам. Есть одна константа EXP_PER_LEVEL и одна функция applyLevelUps.

Обёртка модуля

(function (global) {
  'use strict';

  const STORAGE_KEY = 'levelUpData';
  const EXP_PER_LEVEL = 5;

  // … функции …

  global.SkillsStore = {
    STORAGE_KEY, EXP_PER_LEVEL, generateId, createDefaultSkill,
    normalize, load, save, applyLevelUps, awardXp,
  };
})(window);

Классическая IIFE: внутренние детали не попадают в глобальную область, наружу выставляется один объект window.SkillsStore. Так модуль работает без сборщика и без type="module" — обычным тегом <script> в любом браузере.

generateId()

generateId(): string
function generateId() {
  return global.crypto && typeof global.crypto.randomUUID === 'function'
    ? global.crypto.randomUUID()
    : '_' + Math.random().toString(36).slice(2, 11);
}

Основной путь — криптостойкий UUID. Фолбэк нужен для старых браузеров и для страниц, открытых по http:// с внешнего адреса: crypto.randomUUID доступен только в защищённом контексте. Использован slice, а не устаревший substr.

createDefaultSkill()

createDefaultSkill(): Skill
function createDefaultSkill() {
  return {
    id: generateId(),
    name: 'Default Skill',
    level: 1,
    exp: 0,
    desc: 'Это дефолтный навык. Нажмите для прокачки.',
    default: true,
  };
}

Ровно один навык в наборе имеет default: true. Он существует, чтобы приложению всегда было куда начислять опыт: удалить его нельзя, а отредактировать — можно, но тогда флаг снимается и normalize() создаст новый дефолтный.

normalize()

normalize(data: unknown): { skills: Skill[], tasks: Task[] }
function normalize(data) {
  const safe = data && typeof data === 'object' ? data : {};
  const skills = Array.isArray(safe.skills) ? safe.skills : [];
  const tasks = Array.isArray(safe.tasks) ? safe.tasks : [];

  if (!skills.some((skill) => skill && skill.default)) {
    skills.push(createDefaultSkill());
  }

  skills.forEach((skill) => {
    skill.id = skill.id || generateId();
    skill.level = Number.isFinite(skill.level) && skill.level >= 1 ? skill.level : 1;
    skill.exp = Number.isFinite(skill.exp) && skill.exp >= 0 ? skill.exp : 0;
  });

  return { skills, tasks };
}

Функция-«санитайзер». Она вызывается в трёх местах: при загрузке из localStorage, при импорте JSON-файла пользователем и косвенно при любом старте страницы. Что она гарантирует:

load() и save()

load(): { skills: Skill[], tasks: Task[] }
function load() {
  try {
    return normalize(JSON.parse(global.localStorage.getItem(STORAGE_KEY)));
  } catch (error) {
    console.error('Не удалось прочитать сохранённые данные:', error);
    return normalize(null);
  }
}

JSON.parse(null) возвращает null и не бросает исключение, поэтому первый запуск проходит через тот же путь, что и обычная загрузка. try/catch ловит битую строку в хранилище — в этом случае игрок получает чистый набор данных вместо белого экрана.

save(data): void
function save(data) {
  try {
    global.localStorage.setItem(STORAGE_KEY, JSON.stringify(data));
  } catch (error) {
    console.error('Не удалось сохранить данные:', error);
  }
}

Запись тоже в try/catch: localStorage выбрасывает QuotaExceededError при переполнении и вовсе недоступен в приватном режиме некоторых браузеров. Приложение продолжит работать в памяти, просто без сохранения.

applyLevelUps()

applyLevelUps(skill: Skill): number // сколько уровней получено
/**
 * Повышает уровень столько раз, сколько позволяет накопленный опыт.
 * Прежняя реализация использовала `if`, поэтому награда в 20 XP
 * давала только один уровень, а остаток опыта терялся.
 */
function applyLevelUps(skill) {
  let gained = 0;
  while (skill.exp >= EXP_PER_LEVEL) {
    skill.exp -= EXP_PER_LEVEL;
    skill.level += 1;
    gained += 1;
  }
  return gained;
}

Сердце игровой механики. Функция изменяет переданный объект и возвращает число полученных уровней — вызывающий код сам решает, показывать ли уведомление. Цикл всегда завершается: опыт конечен и уменьшается на 5 за итерацию.

awardXp()

awardXp(amount: number, skillId?: string): { skill: Skill, levelsGained: number } | null
function awardXp(amount, skillId) {
  const xp = Number(amount);
  if (!Number.isFinite(xp) || xp <= 0) return null;

  const data = load();
  const skill = data.skills.find((item) => item.id === skillId) || data.skills[0];
  if (!skill) return null;

  skill.exp += xp;
  const levelsGained = applyLevelUps(skill);
  save(data);

  return { skill, levelsGained };
}

Единственная функция модуля, которая делает полный цикл «загрузить → изменить → сохранить». Именно её вызывает тренажёр памяти:

const result = window.SkillsStore && SkillsStore.awardXp(gained);
if (result && result.levelsGained > 0) {
  feedback.textContent = `Правильно! Навык «${result.skill.name}» — уровень ${result.skill.level}!`;
}
  • Некорректная или нулевая награда молча игнорируется — возвращается null.
  • Если навык с указанным id не найден, опыт получает первый в списке (то есть обычно дефолтный), награда не пропадает.
  • Данные каждый раз перечитываются из хранилища: две открытые вкладки не затрут правки друг друга целиком, хотя полноценной синхронизации между вкладками нет.

Как расширять

Меняете правила прокачки (например, растущую стоимость уровня) — правьте только applyLevelUps и EXP_PER_LEVEL. Страницы менять не придётся: они не знают о формуле ничего. Добавляете поле в навык — добавьте его в createDefaultSkill и в цикл нормализации, тогда старые сохранения автоматически получат значение по умолчанию.
